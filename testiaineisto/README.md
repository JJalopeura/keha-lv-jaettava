# Esimerkkihakemukset

Tässä hakemistossa olevat ZIP-arkistot ovat KEHA LV -demon testaamista varten.
Ne eivät ole sovelluksen käynnistymisen edellytys, eikä niitä lueta automaattisesti
verkkopalveluun. Tuo aineisto sovellukseen vain tarkoituksenmukaisessa
testiympäristössä ja tarkista aina ennen edelleenjakamista, että se soveltuu
vastaanottajalle.
